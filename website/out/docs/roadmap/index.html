Roadmap

Development progress and future plans for the Chasm ecosystem.

Completed Done

Core Infrastructure

  • Rust core library with session harvesting
  • REST + GraphQL + WebSocket API server
  • SQLite database with FTS5 full-text search
  • Cross-platform session format support
  • SSE-based real-time sync
  • Session encryption at rest (AES-256-GCM)
  • Agent launcher for 7 terminal agents
  • File-system watch mode with debounced auto-harvest
  • FTS5 search optimization (snippet/rank, 4KB header)

Web Application

  • Dashboard with statistics overview
  • Chat interface with session replay
  • Agent management and inbox
  • Real-time sync status indicators
  • Session diff/comparison view
  • Export to JSON, Markdown, HTML, PDF
  • Dark mode theme system

Mobile Application

  • Full navigation structure with workspace browser
  • Offline session caching
  • Push notifications for agent messages
  • Biometric authentication (Face ID, Touch ID)

Extensions & Plugins

  • VS Code extension with real-time session recording
  • Chrome/Firefox browser extension
  • JetBrains IDE plugin
  • Vim and Neovim plugins
  • MCP server for AI agent integration

In Progress Active

Q1-Q2 2026

  • Multi-user collaboration and team workspaces
  • Session sharing with permissions
  • Plugin system with event hooks
  • Enhanced multi-model routing

Planned Future

Cloud Sync

  • Optional cloud sync endpoint
  • Team workspace sharing
  • Cross-device session access

AI Intelligence

  • Automatic topic extraction and categorization
  • Session quality scoring
  • Cross-session recommendations
  • Similarity detection with vector embeddings
